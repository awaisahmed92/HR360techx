Payroll

Payroll runs and payslips with the employee record

HR360 TechX can run a regular or off-cycle payroll and keep the payslip on the employee. A USA payroll type is one option in payroll setup, along with weekly (52), biweekly (26), and monthly (12) schedules. The run uses the pay setup and approved time already in the workspace.

Book a payroll demo How a US run is described

Regular runs

A regular run pays active employees for that period. Weekly, biweekly, and monthly schedules are set in payroll setup, so the calendar matches how you already pay people.

Off-cycle runs

A bonus, a correction, or a new joiner can be paid on its own run. An off-cycle payment does not replace the regular salary run.

Payslips

A payslip shows gross pay, deductions, tax, and the net amount for that run. Payslips are released after the run is confirmed. Employees open their own. They do not see anyone else's.

When a figure is wrong

A wrong amount is adjusted on the next run, or on a correction run if it cannot wait. Missing time is approved first, then the pay run picks it up. A re-run replaces draft figures. A run that was already paid is corrected, not silently overwritten.

Pay components, employee pay setup, and payroll reports live in the same workspace as the run, so payroll is not a separate spreadsheet that has to be reconciled by hand.

What this page does not promise

  • HR360 TechX does not file Form 941, Form 940, W-2s, or 1099s.
  • It does not deposit payroll taxes.
  • It does not pay employees for you.
  • The employer is responsible for the accuracy of any return they file.

US employers can read the Form 941, Form 940, and W-2 and 1099 notes. Those pages are general information, not tax advice.
